# Issue tracker

Issues for `tg-drive-cli` live in **GitHub Issues** on the same repository.

- Repository: `thedavidweng/tg-drive-cli`
- Remote: `git@github.com:thedavidweng/tg-drive-cli.git`
- CLI: `gh`

## Creating an issue

```sh
gh issue create --title "..." --body "..."
```

## Reading issues

```sh
gh issue list
gh issue view <number>
```

## PRs as a request surface

`false` — Pull requests are not treated as triage queue items. Use GitHub Issues to track work, then close them with a linked PR.
